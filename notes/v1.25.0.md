# Changelog

This release of the Elastic Cloud SDK Go should be used for ECE Version `3.8.0`.

## Enhancements

### Add BYOK (Bring Your Own Key) settings for deployments. ([#512](https://github.com/elastic/cloud-sdk-go/pull/512))

The `ByokSettings` model is now available in `DeploymentCreateSettings` and `DeploymentSettings`, enabling customer-managed encryption key support when creating or reading deployments.
